# Sistema de gestión de bienes patrimoniales

Aplicación frontend del Trabajo Práctico Integrador N.º II, desarrollada con
React y Vite para integrarse con el sistema de gestión de bienes patrimoniales
del Trabajo Práctico Integrador N.º I.

## Repositorios

- Frontend: https://github.com/palaciosale2231/-trabajo-practico-integrador-2-palacios-
- Backend: configurar la URL del backend del TPI I en `VITE_API_URL`.

## Ramas de trabajo

- `main`: versión principal.
- `develop`: rama de integración.
- `desarrollo-pantallas`: pantallas, componentes y hooks.
- `proteccion-rutas`: rutas públicas, privadas y autenticación.

## Inicio

Las instrucciones para instalar las dependencias y ejecutar el proyecto se
completarán junto con la aplicación.
